اتصال مخزن GitHub

با اتصال، دستیار می‌تواند فایل‌های مخزن انتخابی را بخواند و تغییرات را مستقیم Commit کند؛ Cloudflare سپس سایت را خودکار به‌روزرسانی می‌کند.

توکن در همین گوشی ذخیره می‌شود تا لازم نباشد هر بار واردش کنی؛ به مدل هوش مصنوعی فرستاده نمی‌شود. برای کم‌کردن خطر، توکن را فقط به همین مخزن محدود کن. در GitHub فقط دسترسی همین مخزن و Contents: Read and write بده؛ توکن را در چت یا فایل‌های مخزن نفرست.
